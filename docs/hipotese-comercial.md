Preparado em 08/09/2026 para E05. Este documento organiza uma decisão futura; não implementa
checkout, cobrança, paywall ou preço e não muda o piloto gratuito. O benefício de referência é
o que a landing promete: até sete recomendações explicadas no Telegram, com candidatura feita

com o piloto preservado. Registrar: elegíveis expostos, oferta apresentada, compradores com

decisão. Próximo passo da equipe: responder a tabela acima e abrir uma tarefa própria para
